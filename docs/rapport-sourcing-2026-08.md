## 1 · PARFUM — le produit réglementé (décision la plus importante)

### Ce qui est légal / illégal (vérifié sur sources officielles)
| Action | Statut |
|---|---|
| Vendre un parfum « équivalence » qui *sent comme* un parfum de niche | ✅ Légal — l'odeur n'est pas protégée (Cass. com. 10/12/2013, n° 11-19.872) |
| Écrire ou afficher « inspiré de Byredo », tableaux de correspondance | ❌ Interdit (CJUE L'Oréal c/ Bellure, C-487/07) — vendre sous le nom propre du produit uniquement |
| Copier flacon/packaging d'une marque | ❌ Contrefaçon / parasitisme — jusqu'à 3 ans + 300 000 € (art. L716-10 CPI) |
| Coller une étiquette « Juju » sur les flacons | ⚠️ Ça vous rend **Personne Responsable** (art. 4 §6 règl. 1223/2009) → CPSR + PIF + CPNP obligatoires (≈ 500–1 700 €/formule) — pas pour démarrer |
| Importer du parfum de Chine sans conformité UE | ❌ Illégal à la revente — les marchés sont ciblés : op. « Fragrance » nov. 2025 = 82 000 flacons saisis, dont 1 945 chez UN exposant de marché (Châteauroux, amende 1–2× la valeur + confiscation) |
| Décanter un 100 ml en petits flacons | ❌ Reconditionnement = vous devenez Personne Responsable |

### Votre statut de départ recommandé : **distributeur** (achat UE déjà conforme)
Obligations restantes (légères) : vérifier l'étiquette en français (Personne Responsable UE + INCI + n° de lot + contenance + DDM/PAO), garder les factures avec n° de lots 3 ans, ne pas vendre un produit suspect. Aucun PIF/CPNP à faire.
⚠️ Échéance 31/07/2026 (règl. 2023/1545) : les produits mis sur le marché après cette date doivent étiqueter 80+ allergènes — vérifier les lots récents.

**Exemple rendu France (vérifié douane)** : 200 pinces à 0,80 $ + 55 $ port → droits 2,7 % (NC 9615 11 00) + TVA 20 % + frais ≈ **247 € soit 1,25 €/pièce** → revente 3-5 € = marge ×2,5-4 ; plastique 0,26 $ → revente 2-3 € = marge ×5-10.

### Spécifications à exiger
- Mention écrite « **cellulose acetate** » (les « acétate » < 0,50 $ sont de l'ABS déguisé) — le vrai : lourd, rigide, couleur dans la masse
- **Échantillon physique d'abord** (3-7 j) ; ressort testé 5000+ cycles (point de casse n°1), charnière, bords polis
- Grille de prix par 100/300/500/1000 (les MOQ à 2 pcs sont des appâts)
- Stratégie : tester les styles via AliExpress/grossiste FR → scaler les best-sellers sur Alibaba 300-500 pcs

## 3 · BAG CHARMS — attention au piège « jouet »

### ⚠️ Le point juridique que personne ne vous dira
- Un **porte-clés peluche est juridiquement un JOUET** (guide directive 2009/48/CE) → **CE + EN71-1/2/3 obligatoires** ; la mention « ceci n'est pas un jouet » ne protège pas. En important vous-mêmes, VOUS êtes responsables.
- **Contrefaçon Labubu** : ~150 000 fausses saisies en 2025 ; un forain à Arras : 13 568 articles saisis + 4 000 € d'amende. Jamais le mot « Labubu »/« Pop Mart » (ni à l'achat ni sur le stand), pas de copie visuelle (9 dents en arc).
- **Charms métal** : REACH — nickel ≤ 0,5 µg/cm²/sem, plomb ≤ 0,05 %, cadmium ≤ 0,01 % → exiger « nickel-free » + rapport de test SGS/Intertek vérifiable, ou passer à l'**acier inox 316L** (problème réglé).

## 4 · RÈGLES D'IMPORT (tout produit)

| Poste | Règle |
|---|---|
| Droits de douane | pinces 2,7 % (NC 9615 11 00) · charms 4 % (7117 19 00) ou 2,7 % (8308 90 00 si porte-clés) — vérifier sur RITA/TARIC |
| TVA 20 % | sur (marchandise + transport + assurance + droits) — art. 292 CGI. En micro-entreprise franchise TVA : **non récupérable** (c'est un coût) |
| Franchise 150 € | ❌ supprimée au 1/7/2026 (règl. UE 2026/382) ; B2C ≤ 150 € : forfait 3 €/type d'article ; en pro (EORI) : droits dès le 1er € |
| DDP vs DAP | **DAP recommandé** : en DDP le transitaire chinois sous-déclare souvent → vous êtes redressables. EORI gratuit sur douane.gouv.fr, garder le justificatif de dédouanement |
| GPSR (depuis 13/12/2024) | vos **nom + adresse sur le produit/emballage**, identifiant modèle/lot, avertissements en français, analyse de risque conservée |
| AliExpress | TVA incluse (IOSS) → idéal pour tester ; la conformité (EN71, REACH) reste votre problème |
| Nov. 2026 | identifiants produits obligatoires sur déclarations e-commerce + ~2 €/colis de frais de traitement attendus |
